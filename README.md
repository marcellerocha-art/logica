# Exercícios de Lógica com Python

Repositório com exercícios práticos de lógica de programação utilizando Python. Cada arquivo contém uma solução para um problema específico, abordando conceitos fundamentais como condicionais, loops, cálculos matemáticos e manipulação de dados.

## 📚 Exercícios

| Arquivo | Descrição |
|---------|-----------|
| **calculadora.py** | Calculadora com operações básicas (adição, subtração, multiplicação, divisão) |
| **comercio_industria.py** | Classificação de empresas por tipo (comércio, indústria, serviços) |
| **dia_semana.py** | Conversão de número para nome do dia da semana |
| **imc.py** | Cálculo de Índice de Massa Corporal (IMC) com classificação |
| **media_conceito.py** | Cálculo de média de notas e atribuição de conceitos |
| **menu_opçoes.py** | Sistema de menu com múltiplas opções |
| **reajuste_salario.py** | Cálculo de reajuste salarial com percentual |
| **residencia_normal.py** | Cálculo de tarifa residencial de energia/água |
| **residencia_social.py** | Cálculo de tarifa social residencial |
| **salario_descontos.py** | Cálculo de salário com descontos (INSS, IR, etc) |
| **triangulo.py** | Validação e classificação de triângulos |
| **turno_estudo.py** | Determinação de turno de estudo conforme horário |

## 🚀 Como Usar

1. Clone o repositório:
```bash
git clone https://github.com/marcellerocha-art/logica.git
cd logica
```

2. Execute um exercício:
```bash
python3 calculadora.py
```

3. Siga as instruções do programa e digite os valores conforme solicitado.

## 💻 Requisitos

- Python 3.6 ou superior
- Terminal/Prompt de comando

## 📝 Conceitos Abordados

- ✅ Variáveis e tipos de dados
- ✅ Condicionais (if, elif, else)
- ✅ Operadores lógicos e comparativos
- ✅ Loops (while, for)
- ✅ Funções
- ✅ Entrada e saída de dados
- ✅ Cálculos matemáticos
- ✅ Estruturas de decisão

## 🎯 Objetivo

Esses exercícios foram desenvolvidos para praticar e consolidar os fundamentos de lógica de programação, preparando para conceitos mais avançados como Programação Orientada a Objetos (POO) e estruturas de dados.
